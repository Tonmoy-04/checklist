# Changelog

## v1.0.0 - 2026-10-27

First public release preparation for MyChecklist, a local-first Windows task
planner.

### Included

- Task creation, editing, completion, reopening, cancellation, and persistence.
- Today, Upcoming, Overdue, All Tasks, and Completed views.
- Search, category and priority filtering, and sorting.
- Daily, weekly, and monthly recurring task occurrences with preserved history.
- Statistics, local settings, reminder polling, and SQLite backup/restore.
- Portable, windowed `MyChecklist.exe` build for Windows 10/11 64-bit.

### Known limitations

- Reminders are delivered while the application is open; closed-app reminders
  are not guaranteed.
- A Windows installer is not included.
- Clean-account, DPI-scaling, packaged-GUI, notification, and real-data
  backup/restore checks remain manual release acceptance checks.
- No project license has been selected yet.
